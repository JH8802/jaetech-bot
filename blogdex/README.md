# 블로그 라이터 (개인용)

네이버 블로그용 원고를 만드는 개인용 웹앱입니다. **정보글**과 **맛집글**은 서로 다른 작성 로직(프롬프트·구조·점검 기준)을 씁니다.
검색 노출과 "사람이 쓴 느낌"을 목표로 하며, 설계 근거는 [DESIGN.md](DESIGN.md)에 있습니다.

## 기능

- **글 종류 선택**: 정보글 / 맛집글 (각각 다른 구성·문체·해시태그 규칙)
- **내 경험·방문 소감 입력칸**: 적은 내용이 글의 뼈대가 되고, 적지 않은 사실(가격·메뉴·시간)은 지어내지 않습니다.
- 맛집글: 매장 이름 → 자동 입력(네이버 검색 API, 선택) 또는 직접 입력, 1번 섹션 끝에 `(플레이스 지도 삽입: …)` 줄 자동 삽입
- 제목 자동 생성(후보 5개, `R` 키로 다시), 핵심 키워드 자동 추출(수정 가능)
- 원고 **스트리밍** 생성 → 태그·해시태그 정리 → **품질 점검**(키워드 밀도, 문장 길이 변화, 말투 섞임, 범용 표현, 중복 문장 등)
- 점검에서 주의가 나오면 **[품질 점검 반영해서 다시 쓰기]**
- **복사(`C`)**: 네이버 에디터에 붙여넣을 수 있게 굵게·글자색이 담긴 HTML + 일반 텍스트로 복사
- **내 원고**: 저장·다시 열기·삭제 (SQLite, 원고 텍스트는 기한 없이 보관)
- 옵션: 표시·광고 가드레일(효능 단정·암시 표현 제한, 정보글은 기본 켜짐), 경험 서술 모드(`메모에 있는 것만` / `메모 + 일반 표현 허용`)

아직 없는 것: 사진 업로드·분석·배치(M2), 메뉴·리뷰 키워드 수집(M3), BASIC 설정(M5)

## 실행 방법

```bash
pip install -r blogdex/requirements.txt
# 저장소 루트의 .env 에 ANTHROPIC_API_KEY 를 넣습니다 (.env.example 참고)
python blogdex/app.py          # → http://127.0.0.1:5000
```

API 키 없이 화면만 확인하려면: `BLOGDEX_MOCK=1 python blogdex/app.py` (샘플 원고, 비용 0원)

## 설정 (.env)

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude API 키 | 필수 |
| `BLOGDEX_MODEL` | 사용 모델. 비용을 줄이려면 `claude-sonnet-5-5` | `claude-opus-5-5` |
| `BLOGDEX_EFFORT` | 생각 깊이 `low` / `medium` / `high` (글쓰기는 `high`도 시도해 볼 만함) | `medium` |
| `BLOGDEX_FALLBACKS` | 안전 분류기가 거절하면 서버가 대체 모델로 자동 재시도 (`1`/`0`) | `1` |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 맛집글 매장 검색용 (https://developers.naver.com → '검색') | 없음 |
| `BLOGDEX_DB` | 원고 DB 파일 위치 | `blogdex/data/blogdex.db` |
| `PORT` | 서버 포트 | `5000` |

## 구조

```
blogdex/
├── app.py          # Flask 서버: 제목, 원고 스트리밍(SSE), 다시 쓰기, 원고 목록, 매장 검색
├── prompts.py      # 글 종류별 작문 사양(프롬프트) ← 글의 품질은 여기서 정해집니다
├── postprocess.py  # 태그·해시태그 정리, 지도 줄 삽입, 글자수 계산
├── eval_style.py   # 품질 점검 지표 (키워드, 문장 길이, 말투, 범용 표현, 중복 …)
├── llm.py          # Claude 호출 (스트리밍, 샘플 모드)
├── storage.py      # SQLite 저장소
├── static/index.html
└── tests/          # python -m unittest discover -s blogdex/tests -t blogdex
```

## 글자수 기준

공백 제외, 해시태그 문단 제외, 강조 태그 제거 (원본 3건에서 확인한 규칙). 상한은 강제하지 않습니다.
맛집글 약 2,000자, 정보글 약 2,700자를 목표로 합니다.

## 주의

- 서버는 `127.0.0.1`(본인 PC)에서만 열립니다. 외부에 공개하려면 로그인과 사용량 제한을 먼저 붙여야 합니다.
- **실제 Claude API 호출은 이 코드를 만든 환경에서 테스트하지 못했습니다.** 샘플 모드와 단위 테스트(26개)·브라우저 흐름 테스트만 통과했으니, 처음 실행할 때 오류 메시지가 보이면 알려 주세요.
- 건강·식품 주제의 가드레일은 표현을 줄여 주는 보조 기능입니다. 발행 전 표시·광고 기준 검토는 직접 해 주세요.
