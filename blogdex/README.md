# 블로그 라이터 (개인용)

네이버 블로그용 원고를 만드는 개인용 웹앱입니다. **정보글**과 **맛집글**은 서로 다른 작성 로직(프롬프트·구조·점검 기준)을 씁니다.
검색 노출과 "사람이 쓴 느낌"을 목표로 하며, 설계 근거는 [DESIGN.md](DESIGN.md)에 있습니다.

## 기능

- **항목별 별점 + 한 줄 평(맛집글·호텔·여행 후기)**: 입력 화면의 "별점"에서 항목마다 1~5점(정수)을 고르면 글 끝(해시태그 앞)에 `★ 별점 한눈에 보기` 블록(`맛 ★★★★☆ 4/5` …)이 항상 같은 모양으로 들어가요. 맛집글 기본 항목은 맛·가격·분위기·주차·좌석·테이블 편리성, 호텔·여행 후기는 위치·객실·시설·서비스·식사·가성비이고, 항목 이름은 고쳐 쓰거나 최대 8개까지 늘릴 수 있어요(내 PC에 저장). 점수는 내가 직접 준 값이고 AI는 점수를 만들지 않아요. 글과 **한 줄 평**(글 마지막 문단, AI가 작성)은 이 점수에 어긋나지 않게 쓰여요. 점수를 안 고른 항목은 빠지고, 정보글은 별점 대신 **한 줄 정리**로 마무리해요
- **내 말투 샘플(모든 글 종류에 적용, 언제든 수정)**: 화면 맨 위 "내 말투 샘플"에 평소 쓰는 문장·말버릇·컨셉 설명을 적고 [저장]하면 다음 글부터 정보글·맛집글·호텔 후기 모두에 최우선 말투 기준으로 반영돼요(최대 3,000자, 내 PC의 원고 DB에 저장). 나이나 취향이 달라져 말투가 바뀌면 고쳐서 다시 저장하면 돼요. 샘플 속 사건·장소는 글에 가져오지 않고 말투만 따라 해요
- **고정 말투 컨셉(맛집글·정보글 공통)**: "30대 직장인 부부, 딸 한 명을 키우는 평범한 회사원 — 화려하지 않고 솔직하게 말하듯이, 가끔 가벼운 유머, 긍정적인 말투". 가족·동행 같은 사연은 메모에 있을 때만 쓰고 지어내지 않아요. 건강·효능·안전 문장에는 농담을 붙이지 않아요. 컨셉은 `blogdex/prompts.py`의 `PERSONA`에서 고칠 수 있어요
- **핵심 키워드 1,000자당 4~6회**(줄이지 않은 그대로의 문구) 목표, 점검 하한 4회 / **해시태그는 핵심 키워드 중심 5~10개**(맛집글·호텔·여행 후기는 홈판 규칙으로 10~15개)

- **글 종류 선택**: 정보글 / 맛집글 / **호텔·여행 후기** (각각 다른 구성·문체·해시태그 규칙). 숙소 후기는 위치·체크인 → 객실 → 부대시설·조식 → 총평, 여행·나들이 후기는 가는 길 → 볼거리·코스 → 먹거리 → 총평 구성이고(메모·사진을 보고 AI가 고름), 사진이 많으면 섹션별로 같은 대상 사진을 연달아 놓는 갤러리 형태로 배치해요
- **내 경험·방문 소감 입력칸**: 적은 내용이 글의 뼈대가 되고, 적지 않은 사실(가격·메뉴·시간)은 지어내지 않습니다.
- 맛집글: 매장 이름·업종·주소를 직접 입력(네이버 지도에서 복사), 1번 섹션 끝에 `(플레이스 지도 삽입: …)` 줄 자동 삽입
- **글 구성(목차) 붙여넣기**: 주제·메인/세부 키워드·검색자 니즈·소제목 목차 기획을 붙여넣고 [구성 읽기]를 누르면 제목·키워드 칸이 채워지고(AI 비용 0원), 원고는 소제목을 목차 순서대로 쓰며 품질 점검에 '글 구성 소제목 반영'이 추가돼요. 구성 속 경험·숫자는 메모·사진에도 있어야 쓰이고, 없으면 [확인 필요]로 남아요(투자 생각 제외)
- **네이버 지도 정보 가져오기**: 네이버 지도 화면 캡처(최대 4장)나 복사한 글을 올리고 [정보 읽기]를 누르면 업종·주소·전화와 '매장 정보'(영업시간·휴무·메뉴·가격·주차 등)가 채워져요. 네이버 지도를 프로그램이 직접 긁어오지 않아요. 플레이스 링크([공유] → [링크 복사])를 넣으면 한눈에 보기 박스 마지막 줄(🔗)에 들어가요
- 제목 자동 생성(후보 5개, `R` 키로 다시), 핵심 키워드 자동 추출(수정 가능)
- 원고 **스트리밍** 생성 → 태그·해시태그 정리 → **품질 점검**(키워드 밀도, 문장 길이 변화, 말투 섞임, 범용 표현, 중복 문장 등)
- 점검에서 주의가 나오면 **[품질 점검 반영해서 다시 쓰기]**
- **복사(`C`)**: 네이버 에디터에 붙여넣을 수 있게 굵게·글자색이 담긴 HTML + 일반 텍스트로 복사. "복사에 제목 포함"을 켜 두면 첫 줄이 제목이라 네이버 제목 칸에 붙여넣으면 제목·본문이 나뉘어 들어가요
- 생성할 때마다 **토큰 사용량과 추정 비용**을 결과 아래에 표시
- **내 원고**: 저장·다시 열기·삭제 (SQLite, 원고 텍스트는 기한 없이 보관)
- 본문의 `[확인 필요: …]`는 노란색으로 표시되고, 품질 점검에 "발행 전 확인 필요 N곳"으로 집계됩니다 (직접 확인 후 지우세요)
- 복사하면 `[확인 필요: …]`가 네이버 에디터에서도 굵은 주황색으로 보이고, 복사 버튼에 남은 개수가 표시됩니다(에디터에서 `[확인 필요`를 검색해 모두 채우거나 지우세요)
- **분량 자동 보강(맛집글·호텔·여행 후기)**: 완성된 글이 공백 포함 1,300자에 못 미치고 메모(150자 이상)나 사진이 있으면, 같은 사실 안에서 공백 포함 1,500자를 목표로 한 번 더 풀어 쓰게 호출해요. 메모도 사진도 거의 없으면 지어내지 않으려고 보강하지 않아요. 결과 아래 안내에 "분량이 짧아 한 번 보강했어요(공백 포함 N자 → M자)"가 표시돼요
- **[확인 필요] 채우기 패널**: 결과 아래에 항목별 입력칸이 생겨요. 아는 항목(주소, 가격, 영업시간 등)만 적고 [채운 내용 본문에 넣기]를 누르면 본문의 표시가 그 내용으로 바뀌고 저장·재점검돼요(API 호출 없음, 비용 0원)
- **표시·광고 표현 점검**(가드레일을 켠 글): 제목·본문·해시태그에서 치료·예방·효능·개선·항산화·노화 방지·과장 보증 표현을 목록 기반으로 찾아 품질 점검에 표시하고 본문에 빨간 밑줄로 보여 줘요. 부정·설명 문장('효과를 약속하는 글은 아닙니다')은 '참고'로 내려 점검 결과에 세지 않아요. 법률 판단이 아닌 보조 도구이며, 점검 목록은 `blogdex/adcheck.py`의 `RULES`에서 업무 기준에 맞게 고칠 수 있어요
- 옵션: 표시·광고 가드레일(효능 단정·암시 표현 제한, 정보글은 기본 켜짐), 경험 서술 모드(`메모에 있는 것만` / `메모 + 일반 표현 허용`)

- **사진(정보글 20장 · 맛집글 20장 · 호텔·여행 후기 30장)**: [사진 선택]/[폴더 선택]으로 올리면 브라우저에서 줄여(긴 변 1,280px) 보내고, AI가 먼저 사진에 보이는 것을 살펴본 뒤 글에 반영합니다. 글 속 단독 줄 `사진 N` 자리에 같은 번호 사진을 네이버 에디터에서 직접 올리세요(복사에는 사진이 포함되지 않아요). 번호는 올린 순서이고 ◀ ▶로 바꿀 수 있어요. **글 속 사진 자리는 번호 순서가 아니라 글 흐름에 맞춰** 그 사진을 설명하는 문단 뒤에 놓이고, 복사본의 `사진 N (파일이름)`과 결과 아래 번호표로 어떤 파일인지 찾을 수 있어요. 사진은 서버에 저장하지 않고, 결과 아래 "AI가 본 사진"에서 번호별로 AI가 본 내용을 확인할 수 있어요

- **홈판 규칙(맛집글·호텔·여행 후기 전용)**: 네이버 홈판 노출 글 16개 분석(`homepan-lab` 저장소)에서 정한 규칙을 이 두 글 종류에만 적용해요. 정보글·투자 생각은 그대로예요
  - 글 맨 위 **고지 문단**: 메모에 협찬·제휴·내돈내산 내용이 있으면 그대로 쓰고, 없으면 `[확인 필요: 고지 - 내돈내산/협찬/제휴 중 하나]`를 남겨요. 고지 문단이 없으면 결과 안내에 알려 줘요
  - **🧒 아이와 함께 박스**: 메모·사진에 아이 정보가 있을 때만 한눈에 보기 박스 다음에 `라벨: 값` 줄로 정리(없으면 만들지 않음)
  - **메뉴판·가격표·표시사항 사진**: 목록 전체를 글로 옮기지 않고 대표 2~4개만 가격과 함께, 나머지는 사진으로
  - **표시사항 해석**(원산지·알레르기·맵기 표시가 확인될 때만 1~2문장), **가격 비교·정품 확인**(메모에 가격·근거가 있을 때만)
  - 감정 표현(ㅋㅋ, ^^)은 글 전체 3번 이하, 이모지는 박스 라벨 아이콘으로
  - **분량**: 공백 포함 1,500자 안팎(점검 1,300~1,800자). 결과 화면 글자수에 공백 포함 수치도 함께 보여요
  - **말투**: 해요체 중심(합니다체 20% 이하, 점검 기준도 같음). 내 말투 샘플을 저장하면 그게 우선이에요
  - **해시태그 10~15개**, **강조는 핵심만**(형광펜 1~2 · 굵게 2~4 · 글자색 1~2), **문단 1~2문장(40~60자)**, 사진 사이 1~3문장
  - **내 글 링크 자리**: 시리즈가 아니어도 해시태그 앞에 `(관련 글 링크 삽입: 내 다른 글 1~2개)` 줄이 들어가요
  - 사진 한도(맛집글 20장 · 호텔·여행 후기 40장)는 그대로예요

아직 없는 것: 메뉴·리뷰 키워드 수집(M3), BASIC 설정(M5)

## 실행 방법

**Windows 더블클릭 (추천)**: `blogdex\run_blogdex.bat` 를 더블클릭하면 서버가 켜지고 브라우저가 자동으로 열려요. 우클릭 → 보내기 → 바탕화면에 바로 가기 만들기를 해 두면 아이콘 한 번으로 실행됩니다. 업데이트는 `blogdex\update_blogdex.bat` 를 더블클릭하세요. (검은 창을 닫으면 서버가 꺼져요)

**업데이트 확인**: 화면 오른쪽 위에 `버전 xxxxxxx`가 보이면 서버가 새 코드로 켜진 거예요. 업데이트(`update_blogdex.bat`)한 뒤에는 **켜 둔 검은 창을 닫고 `run_blogdex.bat`을 다시 실행**해야 서버 쪽 수정이 적용돼요(화면 새로고침만으로는 화면 수정만 반영돼요). 버전이 안 보이면 예전 서버가 켜져 있는 거예요.

**명령으로 실행**

```bash
pip install -r blogdex/requirements.txt
# 저장소 루트의 .env 에 ANTHROPIC_API_KEY 를 넣습니다 (.env.example 참고)
python blogdex/app.py          # → http://127.0.0.1:5000
```

API 키 없이 화면만 확인하려면: `BLOGDEX_MOCK=1 python blogdex/app.py` (샘플 원고, 비용 0원)

## 다른 컴퓨터에서 쓰기 (압축 파일)
1. 압축 파일을 원하는 폴더에 풀기(예: `C:\blogdex-test`).
2. Python 3.11 이상 설치(설치 화면에서 "Add python.exe to PATH" 체크).
3. `blogdex\install_blogdex.bat` 실행 → 패키지 설치, `.env` 생성.
4. 메모장으로 `.env` 를 열어 `ANTHROPIC_API_KEY=` 뒤에 키를 넣고 저장. (키 없이 실행하면 샘플 모드)
5. `blogdex\run_blogdex.bat` 실행 → 브라우저가 열림. 헤더의 `버전`은 압축할 때의 버전(VERSION 파일).
- 압축 파일로 받은 폴더는 git 이 없어 `update_blogdex.bat` 이 동작하지 않습니다. 새 버전은 새 압축 파일로 받으세요.
- 내 원고·말투 샘플·별점 항목은 컴퓨터마다 따로 저장됩니다(`blogdex\data\blogdex.db`). 옮기려면 이 파일을 복사하세요.

## 설정 (.env)

모델은 **Claude Sonnet 5.5로 고정**돼 있어요(원고·사진 분석 모두). 바꾸려면 `blogdex/llm.py` 맨 위의 `MODEL` 한 줄을 고치세요.

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude API 키 | 필수 |
| `BLOGDEX_EFFORT` | 생각 깊이 `low` / `medium` / `high` (글쓰기는 `high`도 시도해 볼 만함) | `medium` |
| `BLOGDEX_DB` | 원고 DB 파일 위치 | `blogdex/data/blogdex.db` |
| `PORT` | 서버 포트 | `5000` |

## 구조

```
blogdex/
├── app.py          # Flask 서버: 제목, 원고 스트리밍(SSE), 다시 쓰기, 원고 목록, 매장 검색
├── prompts.py      # 글 종류별 작문 사양(프롬프트) ← 글의 품질은 여기서 정해집니다
├── postprocess.py  # 태그·해시태그 정리, 지도 줄 삽입, 글자수 계산
├── eval_style.py   # 품질 점검 지표 (키워드, 문장 길이, 말투, 범용 표현, 중복 …)
├── adcheck.py      # 표시·광고 주의 표현 목록(RULES)과 검사 ← 업무 기준에 맞게 편집
├── llm.py          # Claude 호출 (스트리밍, 샘플 모드)
├── storage.py      # SQLite 저장소
├── static/index.html
└── tests/          # python -m unittest discover -s blogdex/tests -t blogdex
```

## 글자수 기준

공백 제외, 해시태그 문단 제외, 강조 태그 제거 (원본 3건에서 확인한 규칙). 상한은 강제하지 않습니다.
맛집글 약 2,100자, 정보글 약 2,700자를 목표로 합니다.
