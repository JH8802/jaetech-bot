# 납품가 산출 프로그램

식품 제조사 **예상 원가표 → 납품가** 계산 프로그램. 회사 PC 안에서만 동작하며 외부 전송·AI 호출이 없습니다.

## 설치·실행 (Windows, Python 설치된 PC)
1. 이 저장소를 내려받거나 `pricing` 폴더를 PC에 복사합니다.
2. **혼자 쓸 때**: `pricing\run.bat` 더블클릭 → 브라우저가 열립니다. (처음 한 번만 필요한 패키지 자동 설치)
3. **팀 5명이 함께 쓸 때**: 한 대의 PC(호스트)에서 `pricing\run_shared.bat` 실행 → 비밀번호 입력 →
   화면에 나온 IPv4 주소를 팀원에게 알려주면, 팀원은 브라우저에서 `http://그주소:8501` 로 접속합니다.
   - DB 파일은 호스트 PC 한 곳에만 있어서 동시 입력 충돌이 없습니다. 호스트 PC가 켜져 있어야 합니다.
   - Windows 방화벽 팝업이 뜨면 '개인 네트워크'만 허용하세요.

## 데이터 위치 / 백업
- `pricing\data\pricing.db` (SQLite 파일 1개). **이 파일만 복사해 두면 백업 끝.** git에는 올라가지 않습니다.

## 사용 순서
0. (선택) **엑셀 일괄 등록**: 원료 단가표·부자재 목록을 엑셀로 한 번에 등록 (아래 참고)
1. **설정**: 판관비·물류비·마진 사용 여부와 %, 납품가 반올림 방식 (물류비/마진은 선택 사항, 기본 꺼짐)
2. **원료 단가**: 원료 등록(loss 포함) → 단가 추가 (날짜별 이력, 최신 단가가 자동 적용)
3. **부자재**: 용기·소포장지·카톤 등 단가 / 분류(포장지·소분비·박스비) / loss
4. **제품 관리**: 봉수, 1봉 중량, 배합표(구성비 %), 부자재 수량·입수
5. **견적 계산**: 자동 계산 또는 '납품가 직접 지정'으로 손익 확인 → 이력 저장 → 엑셀 출력(사내용 / 거래처용)

## 엑셀 일괄 등록 (원료·부자재 대량 업로드)
메뉴 `엑셀 일괄 등록` → `빈 양식 받기` → 원료/부자재 시트에 입력 → 업로드 → **미리보기(신규/수정/변경없음/오류)** 확인 → `등록 실행`.
- 지원: `.xlsx`, `.xls`, `.csv`. 시트 이름은 자유이며, 헤더에 `원료명` 또는 `부자재명`이 있으면 자동 인식합니다. 헤더 위의 제목 줄도 괜찮아요.
- 이름이 같으면 **수정**, 없으면 **신규**. **빈 칸은 기존 값 유지**.
- 원료 단가를 넣으면 단가 이력에 추가됩니다(적용일 비우면 오늘). 같은 날짜·같은 단가를 다시 올려도 중복되지 않습니다.
- loss는 `5` 또는 `5%` → 5% (엑셀 % 서식 셀도 인식). `0.05`처럼 소수로만 쓰면 경고가 뜹니다.
- **오류가 한 줄이라도 있으면 전부 취소**되고 어느 시트 몇 행인지 알려줍니다.
- `현재 등록된 마스터 내보내기`로 받은 파일을 고쳐서 다시 올리면 일괄 수정이 됩니다.

## 계산식
```
원물가   = 벌크단가(원/kg) × 1봉중량(g) × 구성비 × 봉수 ÷ 1000
로스     = 원물가 × 로스율(원료별)
부자재   = 단가 × 수량 ÷ 나누는수 × (1+loss)      ※ 분류: 포장지 / 소분비 / 박스비
직접원가 = 원물가 + 선별비 + 로스 + 부자재 + 운송비
납품가   = 직접원가 ÷ (1 − 판관비% − 마진% − 물류비% [×1.1])   → 반올림
```
판관비·마진·물류비는 모두 **납품가 기준 %** 라서, 기존 엑셀처럼 납품가를 손으로 맞추지 않고 한 번에 역산합니다.

```
pip install -r pricing\requirements.txt
python -m pytest pricing
```
- `pricing/tests/test_*.py` : 가짜 숫자로 계산 규칙 검증 (저장소 포함)
- `pricing/tests/private/` : 실제 견적 시트와 대조하는 회귀 테스트 (**원가가 들어 있어 git 제외**)

- 저장소 `.gitignore`가 `*.db`, `*.xls`, `*.xlsx`, `pricing/data/`를 제외합니다. 원가 파일을 저장소에 넣지 마세요.
