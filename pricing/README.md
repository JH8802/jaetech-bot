# 납품가 산출 프로그램

식품 제조사 **예상 원가표 → 납품가** 계산 프로그램. 회사 PC 안에서만 동작하며 외부 전송·AI 호출이 없습니다.

## 다른 사람에게 모의 테스트를 부탁할 때 (문서)
`pricing\docs\` 폴더에 인쇄·배포용 문서가 있습니다.
- **설치_실행_안내서_A4.pdf** — A4 1장. Python 설치부터 실행, 10분 모의 테스트 코스, 문제 해결까지
- **사용설명서.pdf** — 처음 보는 사람을 위한 설명서(24쪽): 용어, 화면 구성, 메뉴별 사용법(스크린샷), 계산 방식, 테스트 시나리오 A~F, FAQ, **의견 기록 양식**
- 배포 방법: `python -m pricing.make_package` 를 실행하면 `dist/납품가산출_모의테스트_배포용.zip`(프로그램 + 두 PDF + 먼저_읽어주세요.txt)이 만들어집니다. `.venv`·`data`·테스트는 자동으로 빠집니다. 이 ZIP을 그대로 전달하세요.
- 문서를 고쳤다면 `python pricing/docs/build_docs.py` 로 PDF를 다시 만듭니다 (안내서가 1쪽을 넘으면 오류로 알려 줌).

## 설치·실행 (Windows, Python 설치된 PC)
1. 이 저장소를 내려받거나 `pricing` 폴더를 PC에 복사합니다.
2. **혼자 쓸 때**: `pricing\run.bat` 더블클릭 → 브라우저가 열립니다. (처음 한 번만 필요한 패키지 자동 설치)
3. **팀 5명이 함께 쓸 때**: 한 대의 PC(호스트)에서 `pricing\run_shared.bat` 실행 → 비밀번호 입력 →
   화면에 나온 IPv4 주소를 팀원에게 알려주면, 팀원은 브라우저에서 `http://그주소:8501` 로 접속합니다.
   - DB 파일은 호스트 PC 한 곳에만 있어서 동시 입력 충돌이 없습니다. 호스트 PC가 켜져 있어야 합니다.
   - Windows 방화벽 팝업이 뜨면 '개인 네트워크'만 허용하세요.

## 데이터 위치 / 백업
- `pricing\data\pricing.db` (SQLite 파일 1개). **이 파일만 복사해 두면 백업 끝.** git에는 올라가지 않습니다.

## 사용 순서
0. (선택) **엑셀 일괄 등록**: 원료 단가표·부자재 목록·일별 환율을 엑셀로 한 번에 등록
1. **설정**: 판관비·물류비·마진 사용 여부와 %, 납품가 반올림 방식 (물류비/마진은 선택 사항, 기본 꺼짐)
2. **환율**: 미국(USD)·베트남(VND)·튀르키예(TRY) 환율 입력, 그 외 나라는 **(기타) 통화 추가**
3. **원료 단가**: 원료 등록(loss·로스팅비·선별비) → 단가 추가 (원화 또는 **외화 단가 + 환율**, 날짜별 이력)
4. **부자재**: 롤포장지·포장지·인케이스·카톤박스·소분비·기타 단가 / loss, 외화 단가도 가능
5. **판매처**: 마트(물류비) / 온라인 업체(수수료·홍보비·기획전·택배비) 등록
6. **제품 관리**: 봉수, 1봉 중량, 배합표(구성비 %), 부자재(고정 수량 / **봉수 연동**), 3PL 이용료, 제품 복사(30입→60입)
7. **견적 계산**: 제품·판매처·**단가·환율 기준일** 선택 → 원가·납품가, 환율 민감도 → 이력 저장 → 엑셀(사내용/거래처용)
8. **가격 추이**: 기간을 정해 일별 가격 그래프·변동률·연도별 변동·환율 영향 조회 → 엑셀

## 원가 항목 (견적서 구성)
| 번호 | 항목 | 프로그램에서 입력하는 곳 |
|---|---|---|
| ① | 원료 비용 | 원료 단가(원/kg) × 배합비 × 봉수 |
| ② | 로스팅 비용 | 원료 마스터 `로스팅비(원/kg)` |
| ③ | 선별 비용 | 원료 마스터 `선별비(원/kg)` + 제품 `공통 선별단가` |
| ④ | 배합비 | 제품 관리 배합표 (구성비 %) |
| ⑤ | 봉수(낱개) | 제품 `봉수` — **봉수 연동** 부자재는 수량이 봉수에 맞춰 자동 계산 |
| ⑥ | 롤 포장지 | 부자재 분류 `롤포장지` |
| ⑦ | 인케이스 | 부자재 분류 `인케이스` |
| ⑧ | 카톤박스 | 부자재 분류 `카톤박스` (나누는 수 = 입수) |
| ⑨ | 원재료 Loss | 원료별 로스율 (수분+소분+선별, 제품별 덮어쓰기 가능) |
| ⑩ | 부자재 Loss | 부자재별 loss (원가 구성 하단에 합계 표시) |
| ⑪ | 기타 | 부자재 분류 `기타` (검사비·스티커 등) |
| ⑫ | 3PL 이용료 | 제품 `3PL 이용료(원/개)` |
| ⑭ | 마트별 물류비 | 판매처(오프라인) `물류비율`·`정액 물류비` |
| ⑮ | 온라인 업체별 수수료 | 판매처(온라인) `수수료율` |
| ⑯ | 온라인 업체별 홍보비 | 판매처(온라인) `홍보비율` |
| ⑰ | 온라인 업체별 기획전 비용 | 판매처(온라인) `기획전 비용률` + `정액` |
| ⑱ | 택배비 | 판매처(온라인) `택배비(원/개)` |

- 소분비·소포장지·롤포장지처럼 **봉수에 비례하는 부자재는 '수량 기준 = 봉수 연동'** 으로 설정하세요. 30입→60입으로 봉수만 바꾸면 자동으로 두 배가 됩니다.
- 판매처를 고르지 않으면 기존처럼 `설정`의 판관비·물류비·마진 기본값을 씁니다.
- 판매처 비용(수수료·홍보비·기획전 %)과 판관비·마진·물류비율은 모두 **납품가 기준 %** 라서 한 번에 역산합니다. (수수료류는 VAT 포함 판매가 기준 옵션 제공)

## 환율 · 외화 단가
- **원료 단가·부자재 화면**의 입력 폼: `기본 원료 단가(원/kg)` → `환율(통화)` 선택 → 외화 단가 → **환율 직접 입력**.
  환율 선택지는 `해당 없음(원화 ₩)` / `미국 ($)` / `베트남 (₫)` / `튀르키예 (₺)` / `(기타) 새 통화 직접 입력`(코드·이름·국가·기호 입력).
  외화를 고르면 원화 단가 칸은 `외화 단가 × 환율`로 자동 계산됩니다. 환율 칸에는 `환율` 메뉴의 최근 값이 미리 채워지며 그대로 고쳐 쓸 수 있습니다.
- **환율 메뉴 ≠ 단가 입력의 환율**: 환율 메뉴는 날짜별 시세 기록(조회·그래프·'자동' 환산용), 단가 입력의 환율은 *그 단가를 받은 당시의 거래 환율*입니다.
- 수입 원료·부자재는 **통화 + 외화 단가**로 입력합니다 (예: 아몬드 7.5$/kg). 환율 방식은 둘 중 선택:
  - **고정(기본)**: 단가를 받은 당시 환율을 직접 입력 → 이후 시세가 바뀌어도 그 단가의 원화 값은 그대로
  - **자동**: '환율' 메뉴의 날짜별 환율을 따라가며 매일 원화 환산 → 환율이 바뀌면 원가도 따라 바뀜 (환율 영향 분석 가능)
- 환율은 `원 / 외화 1단위` 입니다. 단, **베트남 동(VND)은 100동당 원**으로 입력합니다. (기타 통화의 표기 단위는 직접 지정)
- 기본 제공: 미국(USD) · 베트남(VND) · 튀르키예(TRY). **(기타)** 통화(EUR, CNY, AUD…)는 `환율 > (기타) 통화 추가`에서 추가합니다.
- 견적의 **단가·환율 기준일**을 과거로 바꾸면 그 날짜의 원가를 그대로 재현합니다. 적용일이 미래인 단가는 그 날짜가 되어야 적용됩니다.
- `견적 계산 > 환율 변동이 원가에 미치는 영향`: 통화별 환율이 ±5%, ±10% 변하면 직접원가·납품가가 몇 원(%) 변하는지 표시

## 가격 추이 · 변동률 (메뉴: 가격 추이)
| 탭 | 내용 |
|---|---|
| 품목별 일별 추이 | 원료/부자재와 기간(예: 2026-01-03 ~ 2026-06-05)을 고르면 **일별 가격 선 그래프**, 주별·월별 평균 **막대 그래프**, 시작/종료/변동률/최저/최고/평균. 외화 품목은 **현지 단가 변동 × 환율 변동** 으로 원화 변동을 분해 |
| 기간 변동률 순위 | 모든 원료(또는 부자재)의 기간 변동률을 막대 그래프·표로 (상승/하락 품목 수 포함) |
| 연도별 변동 | 품목 × 연도 변동률(전년 말 대비 연말 단가), 연평균·최저·최고 |
| 제품 원가 추이 | 제품 납품가·직접원가가 날짜에 따라 변한 모습 + 원가 구성(원료/로스팅·선별/부자재/운송·3PL) 변화 |
- 모든 조회 결과는 **엑셀로 다운로드** (일별 데이터, 집계, 엑셀 그래프 포함). 환율 이력도 `환율` 메뉴에서 일별 엑셀로 받을 수 있습니다.
- `설정 > 전체 데이터 엑셀`: 원료·부자재 마스터와 단가 이력, 환율 이력, 판매처, 제품 구성(BOM), 견적 이력 요약을 한 파일로.

## 엑셀 일괄 등록 (원료·부자재·환율 대량 업로드)
메뉴 `엑셀 일괄 등록` → `빈 양식 받기` → 원료/부자재/환율 시트에 입력 → 업로드 → **미리보기(신규/수정/변경없음/오류)** 확인 → `등록 실행`.
- 지원: `.xlsx`, `.xls`, `.csv`. 시트 이름은 자유이며, 헤더에 `원료명` 또는 `부자재명`이 있으면 자동 인식합니다. 헤더 위의 제목 줄도 괜찮아요.
- 이름이 같으면 **수정**, 없으면 **신규**. **빈 칸은 기존 값 유지**.
- 단가를 넣으면 단가 이력에 추가됩니다(적용일 비우면 오늘). 같은 날짜·같은 단가를 다시 올려도 중복되지 않습니다.
- 수입 품목은 `통화`(USD/VND/TRY 또는 미국/베트남/튀르키예)와 `외화 단가`를 입력 (원화 단가는 비움). 계약환율은 `고정환율`.
- `환율` 시트: `통화 | 기준일 | 환율(원)` 한 줄에 하루씩 (일별 환율을 한 번에 올릴 수 있음). 환율이 먼저 처리되므로 같은 파일의 외화 단가에 바로 적용됩니다.
- 로스팅비(원/kg)·선별비(원/kg) 열로 원료별 가공비도 올릴 수 있습니다. 부자재 분류: 롤포장지/포장지/인케이스/카톤박스/소분비/기타
- loss는 `5` 또는 `5%` → 5% (엑셀 % 서식 셀도 인식). `0.05`처럼 소수로만 쓰면 경고가 뜹니다.
- **오류가 한 줄이라도 있으면 전부 취소**되고 어느 시트 몇 행인지 알려줍니다.
- `현재 등록된 마스터 내보내기`로 받은 파일을 고쳐서 다시 올리면 일괄 수정이 됩니다.

## 견적 이력
견적 계산 화면에서 **'견적 이력에 저장'** 을 눌러야 이력이 남습니다 (사이드바의 **작성자(내 이름)** 필수).
저장 시점의 입력·단가·규칙·결과가 통째로 보존되어, 나중에 단가가 바뀌어도 그 시점 그대로 다시 볼 수 있습니다.

| 기록 항목 | 내용 |
|---|---|
| 기본 | 견적번호, 일시, 작성자, 제품, 메모 |
| 계산 방식 | **자동 계산 / 납품가 직접 지정** (지정가는 지정한 납품가도 함께) |
| 제품 조건 | 봉수, 1봉 중량, 선별단가, 운송비 |
| 원료별 | 구성비, 벌크단가, **단가 기준일, 단가 출처(마스터 최신단가/제품 직접입력), 원산지, 공급처**, 원물가, 로스율, 로스 |
| 부자재별 | 분류, 기본금액, loss, 합계 |
| 적용 규칙 | 판관비율, 마진율, 물류비율, 물류비 VAT 기준, 반올림 방식 |
| 결과 | 원물가·선별·로스·포장지·소분비·박스비·운송비, 직접원가, 판관비, 마진, 센터도착가, 물류비, 원가합계, 납품가, 실질 마진(금액·%), 경고 |

- **이력 목록 전체 엑셀**: 기간·제품·작성자·계산방식으로 걸러서 `견적목록 / 원료상세 / 부자재상세` 3개 시트로 다운로드 (피벗·필터 용도)
- **두 견적 비교**: A(기준)·B(비교)를 고르면 납품가 변화, 직접원가 변동 요인(영향 큰 순), 항목/원료/부자재/적용 규칙별 차이를 보여주고 엑셀로 저장
- **삭제 잠금**: 기본은 삭제 불가. `설정 > 견적 이력 보호`에서 허용해야 삭제되며, 삭제·허용 변경은 `삭제·권한 기록` 탭에 남습니다.
  `run_shared.bat` 실행 시 **관리자 비밀번호**를 정하면 이 허용 설정은 그 비밀번호를 아는 사람만 바꿀 수 있습니다.
  (비밀번호를 비우면 누구나 풀 수 있는 '실수 방지용' 잠금입니다.)
- 이전 버전에서 저장한 이력도 그대로 열립니다 (새 항목은 빈 칸으로 표시).

## 계산식
```
원물가   = 벌크단가(원/kg) × 1봉중량(g) × 구성비 × 봉수 ÷ 1000
로스     = 원물가 × 로스율(원료별)
부자재   = 단가 × 수량 ÷ 나누는수 × (1+loss)      ※ 분류: 포장지 / 소분비 / 박스비
직접원가 = 원물가 + 선별비 + 로스 + 부자재 + 운송비
납품가   = 직접원가 ÷ (1 − 판관비% − 마진% − 물류비% [×1.1])   → 반올림
```
판관비·마진·물류비는 모두 **납품가 기준 %** 라서, 기존 엑셀처럼 납품가를 손으로 맞추지 않고 한 번에 역산합니다.
