납품가 산출 프로그램 · 설치·실행 안내서

모의 테스트용 (2026-10-03 버전)
내 PC 안에서만 동작 · 외부로 전송되는 데이터 없음
테스트에는 실제 원가를 넣지 마세요 — 예제(가짜) 데이터만 사용 설치 약 10분 · 처음 실행 3~5분 상세 사용법은 「사용설명서」 참고

준비물

① Windows 10 / 11 PC
회사 PC 가능 · 디스크 여유 약 500MB
② Python 3.11 이상
없으면 STEP 1에서 설치 (이미 있으면 건너뜀)
③ 인터넷 연결
처음 실행 때 부품 설치용 (이후엔 불필요)
④ pricing 폴더 또는 ZIP
전달받은 파일 (sample 예제 엑셀 포함)

STEP 1 파이썬 확인 · 설치

  1. 키보드 윈도우키+R → cmd 입력 → Enter → 검은 창에 python --version 입력
  2. Python 3.11 이상이 나오면 STEP 2로. 오류가 나오거나 숫자가 낮으면 설치:
    인터넷 주소창에 python.org/downloads → Download Python → 받은 파일 실행
  3. 설치 첫 화면 맨 아래 "Add python.exe to PATH" 체크 → Install Now
  4. 회사 보안으로 설치가 막히면 IT팀에 "Python 3.11 설치" 요청

STEP 2 폴더 놓기 (가장 중요)

  1. ZIP이면 우클릭 → 모두 압축 풀기 → 위치를 C:\pricing_app 으로 지정
    바탕화면 · OneDrive · [안전폴더] 에는 풀지 마세요 (실행이 막힙니다)
  2. 풀린 곳에 pricing\run.bat 파일이 보이는지 확인
    (폴더 이름은 반드시 pricing, 폴더 안 파일은 옮기지 말 것)
  3. 그 폴더 빈 곳에서 Shift+우클릭 → "여기에 PowerShell 창 열기" (또는 터미널) 후 아래 한 줄 실행:
    Get-ChildItem -Recurse | Unblock-File

STEP 3 실행

  1. pricing\run.bat 더블클릭
  2. 검은 창이 열리고 처음에는 부품 설치(3~5분)가 진행됩니다. 글자가 계속 올라가면 정상 — 기다리세요
  3. 잠시 후 브라우저가 자동으로 열리며 프로그램 화면이 나타납니다
    열리지 않으면 주소창에 http://localhost:8501 입력
  4. 검은 창은 닫지 마세요 — 닫으면 프로그램이 종료됩니다 (작게 줄여 두기)

STEP 4 정상 실행 확인

  • 왼쪽에 🥜 납품가 산출과 메뉴 10개(견적 계산 · 제품 관리 · 원료 단가 · 부자재 · 환율 · 판매처 · 가격 추이 · 엑셀 일괄 등록 · 견적 이력 · 설정)가 보이면 성공
  • 다음 번부터는 run.bat 더블클릭만 하면 바로 실행 (설치 과정 생략)
  • 종료: 검은 창에서 Ctrl+C 또는 창 닫기  |  처음 상태로 되돌리기: 종료 후 pricing\data 폴더 삭제

모의 테스트 10분 코스 (예제 파일: pricing\sample\일괄등록_예제_랜덤데이터.xlsx)

#메뉴해 볼 일이렇게 되면 정상
1(왼쪽 위)사이드바 작성자(내 이름) 칸에 이름 입력견적을 저장할 때 이 이름이 기록됨 (비우면 저장 불가)
2엑셀 일괄 등록예제 엑셀 선택 → 미리보기 확인 → [등록 실행]신규 약 1,100건 · 오류 0 · 풍선 애니메이션
3제품 관리➕ 새 제품 → 제품명, 봉수 30, 1봉 중량 20 입력 → 배합표에 원료 2~3개(구성비 합 100) → 부자재 추가 → [저장]"저장되었습니다"
4견적 계산제품 선택 → 납품가 확인 → 판매처·기준일·계산 방식을 바꿔 보기 → [견적 이력에 저장]납품가가 바뀌고 이력에 저장됨 (판매처는 「판매처」 메뉴에서 1개 만들어야 보임)
5가격 추이원료(예: 아몬드)와 기간 선택 → 선·막대 그래프, 환율 분해 확인 → 엑셀 다운로드일별 그래프와 변동률 표시, 엑셀 저장
6아무 화면제목·입력칸 옆 (?) 에 마우스를 올려 보기항목 설명이 말풍선으로 나타남

문제가 생겼을 때

증상해결
"지정한 장치, 경로 또는 파일에 액세스할 수 없습니다"폴더를 C:\pricing_app 으로 옮기고 STEP 2의 Unblock-File 실행
"파이썬이 설치되어 있지 않습니다"STEP 1 설치 (PATH 체크) 후 새로 run.bat 실행
"부품 설치에 실패했습니다"회사 인터넷이 막은 경우 — IT팀에 pypi.org, files.pythonhosted.org 접속 허용 요청
브라우저가 안 열림 / 빈 화면주소창에 http://localhost:8501
"Port 8501 is already in use"이미 켜 둔 검은 창을 닫고 다시 실행
화면에 빨간 오류 상자화면 캡처 + 하던 작업을 적어 전달 (실제 원가 숫자는 가리기)

꼭 알아두세요

  • 입력한 데이터는 이 PC의 pricing\data 에만 저장됩니다. 다른 사람 PC와 공유되지 않습니다.
  • 예제 엑셀의 숫자는 전부 랜덤 가짜 값입니다. 같은 파일을 두 번 올려도 괜찮습니다.
  • 아직 완성본이 아닙니다. 이상한 점·불편한 점·빠진 기능을 자유롭게 알려 주세요.
  • 프로그램을 업데이트하면 새 ZIP으로 pricing 폴더를 덮어쓰되, data 폴더는 건드리지 마세요.
