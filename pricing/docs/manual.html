1. 이 프로그램은 무엇인가요?

한 줄 요약 — 원료·부자재 단가와 환율을 한 곳에 입력해 두면, 제품별 원가와 납품가를 자동으로 계산하고, 단가가 시간에 따라 얼마나 변했는지(숫자·그래프·엑셀)를 보여 주는 회사 PC 전용 프로그램입니다.

데이터는 어디에 저장되나요?

  • 이 PC의 pricing\data\pricing.db 파일 하나에만 저장됩니다. 인터넷으로 전송되지 않고, 다른 사람 PC와 공유되지 않습니다.
  • 인터넷은 처음 설치할 때 부품을 받는 용도로만 씁니다. 환율도 자동 수집하지 않고 사람이 입력(또는 엑셀 업로드)한 값만 사용합니다.
  • 이 파일만 복사해 두면 백업이 끝납니다. 지우면 처음 상태로 돌아갑니다.

이번 모의 테스트의 목적

① 우리 원가표 작성에 필요한 항목이 빠지지 않았는지 ② 화면과 용어가 이해되는지 ③ 입력이 불편하지 않은지 ④ 계산 방식이 실무와 맞는지 확인하는 것입니다. 맞지 않거나 어색한 부분은 이 문서 맨 뒤 「의견 기록 양식」에 적어 주세요.

2. 먼저 알아둘 용어

화면 곳곳의 (?) 아이콘에 마우스를 올리면 그 항목의 설명이 나옵니다. 아래는 자주 나오는 용어입니다.

용어뜻
봉수한 세트에 들어가는 낱개 수. 하루견과 30입이면 봉수 = 30.
배합비 (구성비)낱개 1봉 안에서 각 원료가 차지하는 비율. 전부 더해 100%가 되어야 합니다 (아몬드 30% + 호두 25% + …).
1봉 중량낱개 1봉의 내용물 무게(g). 원료별 사용량 = 1봉 중량 × 구성비 × 봉수.
로스 (loss)가공·포장 중 줄어들거나 버려지는 비율. 원료는 수분·소분·선별 loss의 합, 부자재는 별도 loss%를 씁니다.
로스팅비 · 선별비원료를 볶고(로스팅) 골라내는(선별) 가공 비용(원/kg). 기본 단가에 이미 포함돼 있으면 0으로 둡니다.
부자재 분류롤포장지 · 포장지 · 인케이스 · 카톤박스 · 소분비 · 기타. 원가 구성표에서 이 분류별로 합산됩니다.
봉수 연동부자재 수량을 수량 × 봉수로 계산. 소포장지·소분비·롤포장지처럼 봉수에 비례하는 부자재에 사용. 인케이스·카톤박스처럼 세트당 고정이면 '고정'.
나누는 수카톤박스 입수처럼 여러 세트가 함께 쓰는 부자재의 단가를 나누는 값 (8입 카톤이면 8).
직접원가원료비 + 로스팅비·선별비 + 원재료 로스 + 부자재 + 운송비 + 3PL 이용료.
센터도착가직접원가 + 판관비 + 마진. 물류센터에 도착한 시점의 가격.
납품가거래처에 청구하는 가격(VAT 별도). 센터도착가에 판매처 비용(물류비·수수료·홍보비·기획전·택배비)까지 더한 원가합계를 기준으로 역산합니다.
납품가 기준 %판관비·마진·수수료 등은 '납품가의 몇 %'입니다. 납품가를 알아야 금액이 나오는 구조라서 프로그램이 한 번에 역산해 줍니다.
실질 마진설정한 마진 + 납품가 반올림으로 남는 차익. 마이너스면 적자입니다.
단가·환율 기준일견적을 계산할 때 이 날짜에 유효한 단가와 환율을 쓰는 기능. 과거 날짜를 고르면 그때의 원가를 재현합니다. 적용일이 미래인 단가는 그날부터 적용됩니다.
환율 (2종류)① 환율 메뉴 = 날짜별 시세 기록(조회·그래프·'자동' 환산용). ② 원료·부자재 입력 화면의 환율 = 그 단가를 받은 당시의 거래 환율(기본은 '고정'). 목적이 다릅니다.
환율 적용 방식고정: 입력한 환율로 계산, 시세가 바뀌어도 그 단가의 원화 값은 그대로. 자동: 환율 메뉴의 날짜별 환율을 따라가 환율이 바뀌면 원화 원가도 바뀜.

3. 화면 구성

첫 화면 — 왼쪽은 메뉴, 오른쪽은 선택한 메뉴의 화면입니다.

메뉴언제 쓰나요?
작성자 (내 이름)왼쪽 위 입력칸. 견적을 저장하려면 꼭 입력해야 합니다. 누가 만든 견적인지 이력에 남습니다.
견적 계산제품을 골라 원가·납품가를 계산하고, 저장하거나 엑셀로 받습니다.
제품 관리제품의 봉수, 배합표(원료 구성비), 부자재 구성을 등록합니다. 제품 복사(30입→60입)도 여기서.
원료 단가원료(견과 등) 정보와 날짜별 단가·환율을 등록합니다.
부자재포장지·인케이스·카톤박스 등 부자재 정보와 날짜별 단가를 등록합니다.
환율미국·베트남·튀르키예·(기타) 통화의 날짜별 환율을 입력하고 이력을 조회합니다.
판매처마트(물류비)·온라인 업체(수수료·홍보비·기획전·택배비)를 등록합니다.
가격 추이원료·부자재 가격이 기간 동안 어떻게 변했는지 그래프·변동률·환율 영향으로 봅니다.
엑셀 일괄 등록원료·부자재 단가와 환율을 엑셀로 한꺼번에 등록합니다.
견적 이력저장한 견적을 조회·엑셀 다운로드·두 견적 비교합니다.
설정판관비·물류비·마진 기본값, 납품가 반올림, 이력 삭제 잠금, 전체 데이터 엑셀 내보내기.

화면 사용 요령

  • 입력한 값은 [저장] 버튼을 눌러야 반영됩니다. 표(table) 오른쪽 위에서 열 정렬·검색·전체 화면 보기가 가능합니다.
  • ⬇ 표시가 있는 버튼은 엑셀 다운로드입니다. 받은 파일은 브라우저 다운로드 폴더에 저장됩니다.
  • 화면이 잘못된 것 같으면 브라우저 새로고침(F5)을 눌러 보세요. 저장된 데이터는 사라지지 않습니다.

4. 사용 순서 한눈에

처음에는 아래 순서대로 하면 막힘이 없습니다. (모의 테스트는 1번에서 예제 엑셀을 올리면 2~5번을 건너뛸 수 있습니다.)

순서메뉴하는 일비고
0작성자사이드바에 내 이름 입력견적 저장에 필요
1설정판관비·물류비·마진 사용 여부와 %, 납품가 반올림 방식 정하기처음 한 번
2환율사용할 통화(미국·베트남·튀르키예, 필요하면 기타)의 환율 입력수입 품목이 있을 때
3원료 단가원료 등록 + 단가(원화 또는 외화) 입력엑셀 일괄 등록 가능
4부자재부자재 등록 + 단가 입력엑셀 일괄 등록 가능
5판매처마트·온라인 업체 비용 등록선택 사항
6제품 관리제품 등록: 봉수, 1봉 중량, 배합표, 부자재 구성제품마다 한 번
7견적 계산제품·판매처·기준일 선택 → 원가·납품가 확인 → 저장 / 엑셀매번
8견적 이력 · 가격 추이저장한 견적 조회·비교, 가격 변동 분석필요할 때

단가가 바뀌었을 때는?

원료 단가(또는 부자재) 메뉴에서 해당 품목을 고르고, 새 단가와 단가 적용일을 입력해 저장하면 이력이 한 줄 추가됩니다. 제품·견적 화면은 별도 수정 없이 새 단가를 자동 반영합니다. 이전 견적 이력은 저장 당시 값 그대로 유지됩니다.

환율이 바뀌었을 때는?

환율 메뉴에 오늘(또는 해당 날짜) 환율을 추가하세요. 환율 방식이 '자동'인 단가는 원화 원가가 따라서 바뀝니다. '고정'(기본)인 단가는 단가를 받은 당시 환율을 그대로 쓰므로 바뀌지 않습니다.

5-1. 엑셀 일괄 등록

하는 일 — 원료·부자재 단가와 일별 환율을 엑셀로 한 번에 등록·수정합니다. 하나씩 입력하는 수고를 크게 줄여 줍니다.

사용 순서

  1. [⬇ 빈 양식 받기]로 양식을 내려받습니다. (이번 테스트는 pricing\sample 폴더의 예제 파일을 그대로 사용)
  2. 양식의 원료 / 부자재 / 환율 시트에 한 줄에 하나씩 입력합니다. 작성방법 시트에 설명이 있습니다.
  3. 엑셀 파일 선택에서 파일을 고르면 미리보기가 나옵니다 — 신규 / 수정 / 변경없음 / 오류 건수.
  4. 오류가 0이면 [✅ 이 내용으로 등록 실행]을 누릅니다.

알아둘 점

  • 이름이 같으면 수정, 없으면 신규. 빈 칸은 기존 값 유지.
  • 오류가 한 줄이라도 있으면 전체가 취소되고 몇 번째 줄인지 알려 줍니다.
  • 같은 품목을 날짜별로 여러 줄 넣으면 단가 이력이 됩니다.
  • 수입 품목은 통화 + 외화 단가로 입력. 베트남 환율은 100동당 원.
  • [현재 등록된 마스터 내보내기] → 엑셀에서 고쳐 다시 올리면 일괄 수정.

예제 파일을 올린 직후의 미리보기 (신규 1,123건 · 수정 38건 · 오류 0)

5-2. 환율

하는 일 — 날짜별 환율 시세를 기록하고, 기간별 환율 그래프를 봅니다.

  1. 위쪽 표에서 등록된 통화(미국 ($) · 베트남 (₫) · 튀르키예 (₺))와 최근 환율을 확인합니다.
  2. 환율 입력: 통화, 기준일, 환율을 입력하고 [💾 환율 저장]. (같은 통화·같은 날짜는 덮어씀) 베트남은 100동당 원.
  3. 다른 나라 통화가 필요하면 ➕ (기타) 통화 추가에서 코드(예: EUR)·이름·국가·기호(€)를 입력합니다.
  4. 환율 이력 조회: 통화와 기간을 고르면 일별 그래프, 시작·종료·변동률·최저·최고·평균 표, 엑셀 다운로드가 나옵니다.

환율 메뉴 — 통화 표, 환율 입력, 이력 조회 그래프

「환율 이력 조회」의 데이터는 어디서 오나요?

  • 위 환율 입력으로 직접 저장한 값 + 엑셀 일괄 등록의 환율 시트로 올린 값만 사용합니다. 인터넷에서 자동으로 가져오지 않습니다(회사 PC 안에서만 동작).
  • 값을 입력하지 않은 날짜는 직전에 입력한 환율이 이어진 것으로 보고 일별로 그립니다(계단 모양). 자주 입력할수록 정확한 추이가 나옵니다.
  • 이 메뉴의 환율 ≠ 원료·부자재 입력 화면의 환율(그 단가를 받은 당시의 거래 환율). 목적이 다릅니다.

5-3. 원료 단가

하는 일 — 원료의 기본 정보와 날짜별 단가를 관리합니다. 수입 원료는 통화·환율과 함께 입력합니다.

사용 순서

  1. 위 표에서 현재 등록된 원료와 단가를 봅니다.
  2. 수정할 원료에서 ➕ 새 원료(또는 기존 원료)를 고릅니다.
  3. 원료명·원산지·공급처·수분/소분/선별 loss를 입력합니다.
  4. 기본 원료 단가(원/kg)를 입력합니다. (원화로 받은 경우)
  5. 수입품이면 환율 (수입 시 통화 선택)에서 미국 ($) / 베트남 (₫) / 튀르키예 (₺) / (기타)를 고르고 외화 단가와 환율을 직접 입력합니다.
  6. 단가 적용일을 확인하고 [💾 원료 저장].

알아둘 점

  • 외화를 고르면 원화 단가 칸은 외화 단가 × 환율로 자동 계산되어 잠깁니다.
  • 환율 칸에는 환율 메뉴의 최근 값이 미리 채워지며 그대로 고쳐 쓸 수 있습니다. 단가를 받은 당시 환율을 넣으세요.
  • 환율 적용 방식: 고정(기본) = 입력한 환율로 고정 / 자동 = 환율 메뉴의 일별 환율을 따라감.
  • 단가를 바꿔 저장하면 이력이 한 줄 추가됩니다. 단가를 안 바꾸고 다른 정보만 고치면 이력은 늘지 않습니다.
  • 화면 아래 단가 이력 표에서 잘못 넣은 줄을 삭제할 수 있습니다.

원료 등록/수정 폼 — 미국($) 선택 시 외화 단가와 환율 입력칸이 나타나고 원화 환산액이 바로 계산됩니다

5-4. 부자재

하는 일 — 롤필름·소포장지·인케이스·카톤박스 등 부자재와 날짜별 단가를 관리합니다. 입력 방법은 원료 단가와 같습니다.

  1. 부자재명, 분류(롤포장지 / 포장지 / 인케이스 / 카톤박스 / 소분비 / 기타), 기본 loss(%)를 입력합니다.
  2. 기본 부자재 단가(원) 또는 환율(통화) 선택 후 외화 단가·환율을 입력하고 [💾 부자재 저장].
  3. 단가가 바뀌면 같은 부자재를 고르고 새 단가·적용일로 저장 → 이력 추가.

부자재 메뉴 — 분류와 loss, 단가·환율 입력

분류는 왜 중요한가요?

견적의 원가 구성 표에서 부자재가 분류별(롤포장지·포장지·인케이스·카톤박스·소분비·기타)로 합산되어 보입니다. 실무의 원가표 항목(⑥ 롤 포장지, ⑦ 인케이스, ⑧ 카톤박스 등)과 맞춰 분류하세요.

5-5. 판매처

하는 일 — 마트(오프라인)와 온라인 업체별 비용을 등록해 두면, 견적에서 판매처만 고르면 해당 비용이 납품가에 반영됩니다.

유형입력 항목
오프라인(마트)물류비율(%), 정액 물류비(원/개), 물류비율을 VAT 포함 납품가 기준으로 계산할지
온라인물류비(위와 동일) + 업체 수수료율, 업체 홍보비율, 기획전 비용률(%) + 정액, 택배비(원/개), 수수료류를 VAT 포함 기준으로 할지
공통이 판매처만 다른 판관비율·마진율을 쓰려면 체크 (체크 안 하면 설정의 기본값)

판매처 등록 화면 (온라인 유형 예시)

알아둘 점

  • % 항목은 모두 납품가 기준, '원/개' 항목은 개당 정액입니다.
  • 판매처 값을 나중에 바꿔도, 이미 저장한 견적 이력은 저장 당시 값 그대로 유지됩니다.
  • 실제 계약 방식(구간별 수수료, 정액제 등)과 다르면 의견 기록 양식에 적어 주세요.

5-6. 제품 관리

하는 일 — 제품 하나를 이루는 봉수, 1봉 중량, 원료 배합, 부자재 구성을 등록합니다.

  1. 제품 선택에서 ➕ 새 제품을 고르고 제품명, 봉수(30입=30), 1봉 중량(g), 운송비·3PL 이용료·공통 선별단가를 입력합니다.
  2. 배합표: 원료를 고르고 구성비(%)를 입력합니다 (합계 100). 로스율·단가를 비우면 원료 마스터 값을 씁니다.
  3. 부자재: 부자재를 고르고 수량, 수량 기준(봉수 연동 / 고정), 나누는 수를 입력합니다.
  4. [💾 저장]. 만든 제품은 견적 계산에서 바로 선택할 수 있습니다.

제품 관리 — 위쪽은 제품 기본 정보, 가운데는 배합표, 아래쪽은 부자재 표

30입 제품을 60입으로 — 제품 복사

화면 아래 📑 이 제품을 복사해서 새 제품 만들기에서 새 이름과 새 봉수를 넣으면 됩니다. '봉수 연동' 부자재(소분비·소포장지·롤필름 등)는 새 봉수에 맞춰 수량이 자동으로 늘고, '고정' 부자재(인케이스·카톤박스)는 그대로입니다.

5-7. 견적 계산

하는 일 — 제품·판매처·기준일을 고르면 원가와 납품가를 계산합니다.

  1. 제품, 판매처(미선택이면 설정의 기본 규칙), 단가·환율 기준일(기본은 오늘)을 고릅니다.
  2. 계산 방식: 납품가 자동 계산 또는 납품가 직접 지정(손익 확인) — 이미 정해진 납품가가 있을 때 얼마가 남는지/적자인지 확인.
  3. 위쪽 큰 숫자 4개를 먼저 봅니다: 납품가 · 원가합계 · 센터도착가 · 실질 마진.
  4. 아래 표에서 원료별 계산(단가·통화·환율·원물가·로스), 부자재별 계산, 원가 구성(항목별 금액)을 확인합니다.
  5. 필요하면 [💾 견적 이력에 저장](사이드바에 작성자 이름 필요) 또는 엑셀 다운로드.

견적 계산 화면 (온라인 판매처 선택 예시)

5-7. 견적 계산 (계속)

결과를 읽는 법

  • 납품가: 거래처에 청구할 가격(VAT 별도).
  • 원가합계: 직접원가 + 판관비 + 마진 + 판매처 비용. 자동 계산에서는 납품가와 거의 같습니다.
  • 센터도착가: 직접원가 + 판관비 + 마진.
  • 실질 마진: 마진 + 반올림 차익. 마이너스면 적자 경고가 뜹니다.
  • 노란 경고 상자: 단가가 없거나, 구성비 합이 100%가 아닌 경우 등 입력을 점검하라는 안내입니다.

저장·엑셀 버튼

  • 💾 견적 이력에 저장: 지금 화면을 그 시점의 단가·환율·규칙 그대로 보관.
  • ⬇ 원가표 엑셀 (사내용): 원료·부자재·원가 구성 전부. 거래처에 보내지 마세요.
  • ⬇ 납품가 엑셀 (거래처용): 제품명과 납품가만. 원가 정보 없음.
  • 전체 제품 한눈에 비교: 같은 판매처·기준일로 모든 제품의 납품가를 표로.

💱 환율 변동이 원가에 미치는 영향 (민감도)

견적 화면 아래 접힌 상자를 열면, 수입 원료·부자재 중 외화 단가인 품목이 직접원가의 몇 %를 차지하는지, 그리고 해당 통화 환율이 ±5%·±10% 변하면 납품가가 몇 원(몇 %) 변하는지를 보여 줍니다. 원화 단가 품목은 영향이 없습니다.

단가·환율 기준일 활용

기준일을 과거 날짜로 바꾸면 그날 유효했던 단가·환율로 계산합니다 (예: 지난 분기 견적 재현). 해당 날짜 이전에 단가 기록이 없으면 가장 오래된 단가를 쓰고 경고를 표시합니다.

5-8. 견적 이력

하는 일 — 저장한 견적을 조회하고, 엑셀로 받고, 두 견적을 비교합니다.

  • 📋 목록·상세: 기간·제품·작성자·계산 방식으로 걸러서 목록을 봅니다. 견적을 고르면 저장 당시 상세가 그대로 나옵니다. ⬇ 이력 목록 전체 엑셀은 견적목록·원료상세·부자재상세 3개 시트로 저장됩니다.
  • ⚖ 두 견적 비교: A(기준)와 B를 고르면 납품가 변화, 변동 요인(영향 큰 순), 항목별·원료별·부자재별 차이, 적용 규칙 차이를 보여 줍니다.
  • 🗂 삭제·권한 기록: 삭제와 삭제 허용 변경 기록.

두 견적 비교 — 단가가 달라진 원인이 요인 순위로 표시됩니다

견적 삭제는 기본적으로 잠겨 있습니다

여러 명이 쓸 때 실수로 지우는 것을 막기 위해, 설정 메뉴에서 허용해야 삭제할 수 있습니다. 삭제하면 기록이 남습니다.

5-9. 가격 추이

하는 일 — 원료·부자재 단가가 기간 동안 어떻게 변했는지 보고, 오르내린 이유가 현지 가격 때문인지 환율 때문인지 확인합니다. 4개 탭이 있습니다.

① 품목별 일별 추이

  1. 구분(원료/부자재)과 품목, 조회 기간(예: 2026-01-03 ~ 2026-06-05)을 고릅니다.
  2. 시작·종료 단가, 변동액·변동률, 가격이 바뀐 날 수, 최저·최고·평균이 나옵니다.
  3. 그래프를 선(일별) 또는 막대(주별·월별 평균)로 바꿔 봅니다.
  4. 수입 품목은 변동 원인 분해가 나옵니다: 원화 단가 변동 = 현지 단가 변동 효과 + 환율 변동 효과.
  5. ⬇ 엑셀로 일별 데이터·집계·그래프를 저장합니다.

① 품목별 일별 추이 — 시작·종료 단가, 변동률, 일별 선 그래프 (수입 원료 예시)

5-9. 가격 추이 (계속)

수입 원료의 변동 원인 분해 — 현지 단가 +2.5%, 환율 +0.2% → 원화 단가 +2.7% (아래 그래프는 시작일=100 지수)

② 기간 변동률 순위

모든 원료(또는 부자재)의 기간 변동률을 막대 그래프와 표로 비교합니다. 상승·하락·변동 없음 품목 수도 보여 줍니다. 수입 품목은 현지가 효과와 환율 효과가 따로 표시됩니다.

② 기간 변동률 순위

③ 연도별 변동 · ④ 제품 원가 추이

  • 연도별 변동: 연도를 골라 품목별 전년 말 대비 연말 단가 변동률, 연평균·최저·최고를 봅니다 (매년 몇 % 올랐는지).
  • 제품 원가 추이: 제품·판매처·간격(일/주/월)을 고르면 그 날짜의 단가·환율로 다시 계산한 납품가·직접원가 추이와 원가 구성 변화를 보여 줍니다. (아래 페이지)

5-9. 가격 추이 (제품 원가 추이)

④ 제품 원가 추이 — 납품가·직접원가 선 그래프와 원가 구성(누적 막대)

이 탭을 볼 때 주의할 점

  • 저장된 견적 이력이 아니라, 각 날짜의 단가·환율로 현재 제품 구성을 다시 계산한 값입니다.
  • 제품 배합·부자재 수량은 현재 설정 그대로입니다 (과거에 배합이 달랐다면 반영되지 않음).
  • 기간이 길면 간격을 주·월로 바꾸세요.

모든 조회 결과는 엑셀로 내려받을 수 있습니다

각 탭 아래 ⬇ 엑셀 버튼 — 일별 데이터, 집계, 변동률, 연도별 표, 엑셀 그래프가 포함됩니다. 환율 이력은 환율 메뉴, 전체 데이터는 설정 메뉴에서도 받을 수 있습니다.

하는 일 — 견적 계산의 기본 규칙과 이력 보호, 전체 데이터 내보내기를 설정합니다.

설정 화면

6. 원가 계산 방식

프로그램이 하는 계산을 순서대로 적었습니다. 기존 엑셀 원가표와 숫자가 다르면 아래 식과 비교해 보세요.

단계계산식
① 원물가 (원료별)단가(원/kg) × 1봉 중량(g) × 구성비 × 봉수 ÷ 1000  (외화 단가는 환율로 원화 환산한 값)
② 로스팅비 · 선별비로스팅(선별) 단가(원/kg) × 원료 중량(kg). 제품 공통 선별단가는 총 중량에 적용
③ 원재료 로스원물가 × 로스율 (수분+소분+선별 loss, 제품에서 개별 지정 가능)
④ 부자재단가 × 수량 ÷ 나누는 수 × (1 + loss). 수량이 '봉수 연동'이면 수량 × 봉수
⑤ 직접원가① + ② + ③ + ④ + 운송비 + 3PL 이용료
⑥ 센터도착가직접원가 + 판관비 + 마진
⑦ 판매처 비용물류비(% + 정액) + 온라인 수수료 + 홍보비 + 기획전 비용(% + 정액) + 택배비
⑧ 원가합계센터도착가 + 판매처 비용
⑨ 납품가(직접원가 + 정액 판매처 비용) ÷ (1 − 판관비% − 마진% − 물류비% − 수수료% − 홍보비% − 기획전%) 후 반올림

왜 이렇게 역산하나요?

판관비·마진·수수료 등은 '납품가의 몇 %'입니다. 납품가가 정해져야 금액이 나오는데 납품가는 그 금액을 포함해서 정해지므로 서로 물려 있습니다. 기존 엑셀은 납품가를 손으로 바꿔 가며 맞췄지만, 이 프로그램은 위 ⑨번 식으로 한 번에 풉니다.

숫자가 기존 엑셀과 다를 때 먼저 확인할 것

  • 배합표 구성비 합계가 100%인가? (아니면 경고가 표시됩니다)
  • 원료·부자재 단가의 적용일과 기준일이 맞는가? 환율 방식(고정/자동)과 환율 값이 맞는가?
  • 부자재의 수량 기준(봉수 연동/고정)과 나누는 수가 엑셀 시트와 같은가?
  • 설정의 판관비·물류비·마진 사용 여부와 %, 납품가 반올림 방식이 엑셀과 같은가?
  • 엑셀에서 특정 원료 단가에 1.1 같은 배율을 따로 곱하지는 않았는가? (이 프로그램은 입력한 단가를 그대로 씁니다)

7. 모의 테스트 시나리오

예제 파일(pricing\sample\일괄등록_예제_랜덤데이터.xlsx)을 엑셀 일괄 등록으로 먼저 올려 둔 상태에서 진행하세요. 각 시나리오가 끝나면 마지막 장 의견 기록 양식에 느낌을 적어 주세요.

A 제품 만들고 첫 견적 내기 (10분)

  1. 사이드바 작성자에 이름 입력.
  2. 제품 관리 → ➕ 새 제품: 이름 "테스트 견과 30입", 봉수 30, 1봉 중량 20, 운송비 300, 3PL 250.
  3. 배합표: 아몬드(미국산) 40 · 호두(미국산) 30 · 건포도(미국산) 30 (합계 100). 부자재: 롤필름 / 소분 봉투 / 소포장지(수량 1, 봉수 연동), 인케이스(PET) 1 고정, 카톤박스(8입) 1 고정·나누는 수 8. 저장.
  4. 견적 계산에서 제품 선택 → 납품가·원가 구성 확인 → [견적 이력에 저장].

확인 포인트 원료·부자재 표의 계산이 이해되는가? 용어가 어려운 곳이 있는가? 입력이 번거로운 곳은?

B 판매처에 따라 납품가가 얼마나 달라지나?

  1. 판매처: 오프라인 "○○마트"(물류비 3% + 정액 100, 마진 5%), 온라인 "△△몰"(수수료 12%, 홍보비 2%, 기획전 1%, 택배비 3,000)을 등록.
  2. 견적 계산에서 판매처를 (기본 설정) → ○○마트 → △△몰로 바꾸며 납품가·원가 구성이 어떻게 달라지는지 봅니다.

확인 포인트 우리 실제 비용 항목(마트별 물류비, 온라인 수수료·홍보비·기획전·택배비)이 빠짐없이 들어 있는가? 계산 방식(납품가 기준 %)이 실무와 맞는가?

C 환율이 오르면 원가가 얼마나 변하나?

  1. 견적 계산에서 💱 환율 변동이 원가에 미치는 영향 상자를 열어 USD 환율 ±5%·±10%의 납품가 영향을 봅니다.
  2. 환율 메뉴에서 USD의 오늘 환율을 현재보다 5% 높게 입력·저장합니다.
  3. 다시 견적 계산: 환율 '자동' 단가가 올랐는지, 1번의 예상과 비슷한지 비교합니다. (예제의 피칸 한 줄은 고정환율이라 변하지 않습니다.)

확인 포인트 환율 입력 방식(환율 메뉴 vs 단가 입력 화면)이 이해되는가? 실무에서는 어느 쪽 환율을 쓰는가?

7. 모의 테스트 시나리오 (계속)

D 단가가 바뀐 기록 남기고 변동 확인하기

  1. 원료 단가: 기존 원료(예: 호두(미국산)) 선택 → 외화 단가를 현재보다 약 10% 높게, 적용일은 오늘로 입력 → 저장.
  2. 화면 아래 단가 이력에 줄이 추가되었는지 확인.
  3. 가격 추이 → 품목별 일별 추이: 같은 원료, 기간 "6개월 전 ~ 오늘" 선택 → 변동률·그래프·환율 분해 확인 → 엑셀 다운로드.
  4. 기간 변동률 순위에서 어떤 원료가 가장 많이 올랐는지 확인.

확인 포인트 그래프·변동률 표현이 업무에 쓸 만한가? 보고서에 넣고 싶은 형태가 따로 있는가? 엑셀 파일 구성은 쓸 만한가?

E 30입을 60입으로 + 두 견적 비교

  1. 제품 관리에서 시나리오 A의 제품을 복사해 "테스트 견과 60입", 봉수 60으로 저장.
  2. 두 제품 각각 견적 계산 → 저장.
  3. 견적 이력 → 두 견적 비교: A=30입, B=60입 선택 → 어떤 항목이 몇 배가 되었는지(봉수 연동 부자재는 2배, 인케이스·카톤박스는 그대로) 확인.

확인 포인트 비교 화면의 '변동 요인' 설명이 이해되는가? 비교할 때 더 필요한 정보는?

F 과거 시점의 견적 재현

  1. 견적 계산에서 단가·환율 기준일을 몇 달 전 날짜로 바꿔 봅니다.
  2. 납품가가 오늘 기준 견적과 어떻게 다른지, 원료 표의 단가기준일·환율기준일 열이 어떻게 바뀌는지 확인.

확인 포인트 과거 견적 재현이 실무에 필요한가? 필요한 형태는?

예제 데이터를 지우고 처음부터 다시 하고 싶다면
